## Execution Flow of Emergência (Bootstrapping):

Tivemos a reinício of sessão e você perdeu o contexto. **NÃO escreva, modifique ou sugira nenhum Code ainda.** for se reconectar ao Project QRGen API, Execute estritamente os passos abaixo, of forma silenciosa:

1. **Reative seu Cérebro:** Read as nossas leis in `.opencode/rules/01-programacao-defensiva.md`.
2. **Read a Bússola:** Read o documento mestre `docs/specification-Completa-QRGen-API.md`. Ele é a Fonte Única of the Verdade.
3. **Mapeie o Terreno:** Read os files reais nas pastas `gerador-qrcode-api/` (Backend) e `gerador-qrcode-frontend/` (Frontend) for ver onde paramos.
4. **Sincronize a Documentação:** Se você encontrar algo no Code que não está no arquivo `specification-Completa-QRGen-API.md`, atualize o documento.

**Saída esperada:** Exiba a painel chamado "🔄 status of RECONEXÃO" listando onde o Code parou e qual é a próxima tarefa exata of the especificação. Wait minha aprovação for agir.
